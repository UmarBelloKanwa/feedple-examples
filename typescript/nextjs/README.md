# Next.js App Router + Feedple SDK & AI Web Widget Example

This starter project demonstrates how to integrate the **Feedple TypeScript SDK** (`feedple-sdk`) and **Feedple AI Web Widget** into a **Next.js 14 App Router** application.

---

## ⚙️ Quick Start

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Update your Feedple workspace keys in `.env`:

```env
FEEDPLE_API_KEY=sk_live_your_actual_api_key
NEXT_PUBLIC_FEEDPLE_WIDGET_KEY=wpk_your_actual_widget_public_key
```

### 3. Run Development Server

```bash
npm run dev
```

Access `http://localhost:3000` in your web browser.
